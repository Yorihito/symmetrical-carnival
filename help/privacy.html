プライバシーポリシー

AVR Controller は、個人情報を自動的に収集・保存・送信・共有することはありません。

本アプリがネットワーク通信を行うのは、お使いの端末と同一のローカルネットワーク上にある対応 AV レシーバーを制御するためのみです。氏名・メールアドレス・位置情報・広告識別子などの個人情報や端末識別子を自動的に取得することはありません。

サードパーティ製の解析（アナリティクス）SDK、広告 SDK、トラッキング技術は一切使用していません。

ローカルネットワーク情報の扱い

接続先 AVR の IP アドレスなどのネットワーク情報は、お使いの端末内（設定）にのみ保存されます。開発者や外部サーバーに送信されることはありません。

例外: ご意見・ご要望の送信について

アプリ内の「設定」→「ご意見・ご要望を送る」（以前のバージョンでは「問題を報告」）を使うと、GitHub 上のパブリックな Issue（課題）としてバグ報告や機能リクエストを投稿できます。この機能を使う場合:

  • 送信されるのは、あなたがタイトル・本文欄に入力した内容と、端末情報（アプリのバージョン、OS の種類とバージョン、機種名、言語設定など）です。IP アドレスなどのネットワーク情報は含まれません。
  • 送信前に内容を確認・編集できます。
  • この内容は GitHub 上で誰でも閲覧できる形で公開されます。メールアドレスなど、公開されて困る個人情報は本文に書かないでください。
  • 報告は AVR Controller 用の Cloudflare Worker を経由して GitHub に送信される場合があります。Worker が未設定または利用できない場合は、報告内容を入力済みの GitHub Issue 作成画面をブラウザで開きます。
  • この機能を使わない限り、アプリから開発者または外部サービスにデータが送信されることはありません。

開発の応援（アプリ内課金）について

  • 「開発を応援する」の購入は Apple の App Store が処理します。開発者がお支払い情報を受け取ることはありません。
  • 応援したという事実（初めて応援した日時のみ）は、お使いの端末のキーチェーンに保存されます。iCloud キーチェーンが有効な場合は、同じ Apple ID の端末間で同期されます。金額や回数は保存しません。
  • 応援したあとに「ご意見・ご要望を送る」で「サポーターとして送信する」をオンにして送ると、公開される Issue に「supporter」ラベルが付きます。オフにすれば付きません。
