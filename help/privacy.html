プライバシーポリシー

AVR Controller（Denon / Marantz AVR コントローラー）は、個人情報を自動的に収集・保存・送信・共有することはありません。

本アプリがネットワーク通信を行うのは、お使いの端末と同一のローカルネットワーク上にある対応 AV レシーバーを制御するためのみです。氏名・メールアドレス・位置情報・広告識別子などの個人情報や端末識別子を自動的に取得することはありません。

サードパーティ製の解析（アナリティクス）SDK、広告 SDK、トラッキング技術は一切使用していません。

ローカルネットワーク情報の扱い

接続先 AVR の IP アドレスなどのネットワーク情報は、お使いの端末内（設定）にのみ保存されます。開発者や外部サーバーに送信されることはありません。

例外: 問題を報告 / 機能リクエスト機能について

アプリ内の「設定」→「問題を報告」を使うと、GitHub 上のパブリックな Issue（課題）としてバグ報告や機能リクエストを投稿できます。この機能を使う場合:

  • 送信されるのは、あなたがタイトル・本文欄に入力した内容と、端末情報（アプリのバージョン、OS の種類とバージョン、機種名、言語設定など）です。IP アドレスなどのネットワーク情報は含まれません。
  • 送信前に内容を確認・編集できます。
  • この内容は GitHub 上で誰でも閲覧できる形で公開されます。メールアドレスなど、公開されて困る個人情報は本文に書かないでください。
  • この機能を使わない限り、アプリから外部にデータが送信されることはありません。
