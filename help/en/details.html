Details

Supported models, network requirements, troubleshooting, and how to report issues.

Supported Models

Works with AV receivers that support network control. Verified on the Denon AVR-X3800H and the Yamaha RX-V581. Check your receiver's manual or product page to confirm it supports network control.

This is an unofficial app made by an independent developer and is not affiliated with any manufacturer. Product names are used only to indicate compatibility; trademarks belong to their respective owners.

Reports from users are collected in the supported models list.

Network Requirements

Same network

Your AVR and the device running the app must be on the same Wi-Fi / LAN. Guest networks or band-steered SSIDs that isolate clients may prevent discovery.

Ports used

Denon and Marantz receivers are controlled over HTTP (TCP 8080) and send status updates over Telnet (TCP 23). Yamaha receivers are controlled over HTTP (TCP 80) and send status updates over UDP. Make sure these aren't blocked by your router or receiver.

If the IP address changes

If your AVR's IP address changes via DHCP, the app re-discovers it by MAC address and attempts to reconnect automatically. If that fails, use "Search for devices" to reconnect manually.

About the macOS App

The macOS app lives in your menu bar. Use the menu bar icon for quick power/volume/input control, or open the main window for the full interface. You can also configure it to launch as a menu-bar-only app (no Dock icon) in Settings.

Using it on iPad

The iPad layout supports a split view and works alongside Split View / Stage Manager for multitasking.

Reporting Bugs & Feature Requests

Use Settings → "Send Feedback" (called "Report a Problem" in earlier versions) in the app, choose a category (Bug / Feature Request / Other), and send. This creates a public GitHub Issue, so please don't include personal information such as your email address in the body. See the Privacy Policy for details.

If you have a GitHub account, you can also file reports directly on the Issues page.

Supporting Development (version 1.1.0 and later)

Every feature of AVR Controller is free. If you enjoy the app, you can tip to support development from Settings → "Support Development", choosing from three amounts. You can tip as often as you like, and tipping doesn't change any features.

Requests from supporters are given priority consideration. After tipping, feedback you send from "Send Feedback" arrives on GitHub with a "supporter" label (you can turn this off when sending; the label is public). We can't promise to implement every request, but supporters' requests are reviewed first.
