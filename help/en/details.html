Details

Supported models, network requirements, troubleshooting, and how to report issues.

Supported Models

Any network-enabled Denon / Marantz AV Receiver (HTTP API on port 8080) is supported; HEOS-ready models are recommended. Verified on the Denon AVR-X3800H. Check your receiver's manual or product page to confirm it supports network control.

Network Requirements

Same network

Your AVR and the device running the app must be on the same Wi-Fi / LAN. Guest networks or band-steered SSIDs that isolate clients may prevent discovery.

Ports used

Control uses HTTP (TCP 8080); some status notifications use Telnet (TCP 23). Make sure these ports aren't blocked by your router or receiver.

If the IP address changes

If your AVR's IP address changes via DHCP, the app re-discovers it by MAC address and attempts to reconnect automatically. If that fails, use "Search for devices" to reconnect manually.

About the macOS App

The macOS app lives in your menu bar. Use the menu bar icon for quick power/volume/input control, or open the main window for the full interface. You can also configure it to launch as a menu-bar-only app (no Dock icon) in Settings.

Using it on iPad

The iPad layout supports a split view and works alongside Split View / Stage Manager for multitasking.

Reporting Bugs & Feature Requests

Use Settings → "Report a Problem" in the app, choose a category (Bug / Feature Request / Other), and send. This creates a public GitHub Issue, so please don't include personal information such as your email address in the body. See the Privacy Policy for details.

If you have a GitHub account, you can also file reports directly on the Issues page.
