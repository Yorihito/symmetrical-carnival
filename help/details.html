詳細ガイド

対応機種、ネットワーク要件、トラブルシューティング、問題報告の方法について説明します。

対応機種

ネットワーク機能（HTTP API / ポート 8080）を備えた Denon / Marantz 製 AV レシーバーに対応しています。HEOS 対応モデルを推奨します。動作確認済み機種は Denon AVR-X3800H です。お使いの AVR がネットワーク制御に対応しているかは、取扱説明書や製品ページでご確認ください。

ネットワーク要件

同一ネットワーク

AVR とアプリを実行する端末が、同じ Wi-Fi / LAN 上にある必要があります。ゲストネットワークやバンドステアリングで分離された Wi-Fi では検出できないことがあります。

使用ポート

制御には HTTP（TCP 8080）、一部の状態通知には Telnet（TCP 23）を使用します。ルーターや AVR 側のファイアウォール設定でこれらのポートがブロックされていないことをご確認ください。

IP アドレスが変わった場合

AVR の IP アドレスが DHCP で変わった場合でも、アプリは MAC アドレスをもとに再検出し、自動的に再接続を試みます。うまくいかない場合は「デバイスを検索」から手動で再接続してください。

macOS 版について

macOS 版はメニューバー常駐アプリです。メニューバーアイコンから素早く電源・音量・入力を操作でき、詳細な画面はメインウィンドウから開けます。「設定」で起動時にメニューバーのみで起動する（Dock アイコンなし）ことも可能です。

iPad での利用

iPad では左右分割のレイアウトに対応しており、Split View や Stage Manager を使いながら他のアプリと並べて操作できます。

不具合報告・機能リクエスト

アプリ内の「設定」→「問題を報告」から、種類（バグ報告 / 機能リクエスト / その他）を選んで送信できます。送信内容は GitHub 上で公開されるパブリックな Issue になりますので、メールアドレスなどの個人情報は書かないでください。詳しくはプライバシーポリシーをご覧ください。

GitHub アカウントをお持ちの方は、直接 Issues ページからも報告・リクエストいただけます。
