AVR Controller is a remote control app for network-enabled AV receivers (AVRs) on the same local network. It uses the receiver's local network control commands (HTTP and Telnet). It requires a compatible network-connected receiver. Without one, the app cannot connect and stays on the connection screen (device search / manual IP address entry). This is expected behavior.

Tested model: Denon AVR-X3800H.

THIRD-PARTY NAMES (Guidelines 5.2.1 and 4.1(a))
- This is an unofficial app by an independent developer. It is not affiliated with, endorsed by, or sponsored by any receiver manufacturer.
- In this build and its metadata, the manufacturer's name has been removed from the app name, subtitle, keywords, screenshots, and in-app text. The only remaining reference is one sentence in the description naming the model the app was tested on, together with a non-affiliation notice, so customers can check compatibility.
- The app contains no third-party logos, artwork, or other content.

HOW TO REVIEW WITHOUT A RECEIVER
- The Settings screen can be opened without a receiver. On iPhone it is in the More tab; on iPad it is in the sidebar.
- The in-app purchases (see below) are in Settings > Support Development and can be purchased without a receiver.

NETWORK USE
- Receiver control uses the local network only: HTTP (mainly port 8080) and Telnet (port 23) to the receiver.
- The Local Network permission is used only to discover and control compatible receivers.
- The app sends data to an external service only when the user explicitly uses Settings > Send Feedback. The report is posted as a public GitHub issue through a Cloudflare Worker operated for this app. If the Worker is unavailable, the app opens a prefilled GitHub issue page in the browser instead.
- There is no analytics, advertising, or tracking.
