# App Review 情報（レビュアー向けノート）

App Store Connect の「App Review 情報 > メモ」欄に、次回提出時から転記する。

## 動作確認に外部ハードウェアが必要（重要）

本アプリは、**同一 LAN 上にネットワーク接続された Denon / Marantz 製 AV レシーバー（AVR）**を制御する
リモコンアプリです。レビュー環境に対応 AVR が無い場合、接続画面（デバイス検索/IP 手動入力）から
先に進めないのは仕様です。

- 動作確認済み機種: Denon AVR-X3800H（HEOS 対応モデル）
- 通信方式: 通常のAVR操作はローカルネットワーク上のHTTP（主にポート8080）およびTelnet（ポート23）を使用します。
- 外部通信: ユーザーが設定画面の「ご意見・ご要望を送る」を明示的に使用した場合のみ、報告内容をCloudflare Worker経由で公開GitHub Issueとして送信します。Worker未設定・利用不可時は、入力済みのGitHub Issue作成画面をブラウザで開きます。通常のAVR操作、解析、広告、追跡のための外部通信はありません。
- ログイン/アカウント登録は不要です（アプリ内に認証機能はありません）。

## アプリ内課金（開発の応援）

- 「設定」→「開発を応援する」に、開発者への投げ銭（tip）として消耗型 IAP を 3 つ用意しています
  （`cc.nyoyapoya.denoncontroller.tip.small` / `.tip.medium` / `.tip.large`）。
- **購入してもアプリ内の機能やコンテンツは一切解放されません**。すべての機能は無料のままです。
- 設定タブから開けるため、AVR が無い環境でも購入までの流れを確認できます。
- 応援した方が「ご意見・ご要望を送る」から送ると、Issue に `supporter` ラベルが付き、開発者が要望を
  優先的に検討します。これは開発者側の対応方針で、アプリ内の機能の解放ではありません。

## 補足

- ローカルネットワーク権限（`NSLocalNetworkUsageDescription`）は AVR 検出・制御のためのみに使用します。
- サインインは不要のため、ASC の「Sign-in required」はオフのままにしてください。
