# 音量ダイアル改善 設計・実装記録

## 目的

Main Zoneの音量操作に、アプリアイコンをモチーフにした円形ダイアルを追加する。回転量に応じて細かく
値が変わる手触りを持たせつつ、既存ユーザーが慣れている横型スライダーはそのまま残す。

## ユーザー体験

- 初期値は従来どおり「スライダー」。アップデートで操作方法を強制変更しない。
- 設定の「音量コントロール」で「スライダー」と「ダイアル」をいつでも切り替えられる。
- 新しいダイアルの紹介は、AVRへの接続が初めて成功したタイミングで1回だけ表示する。
- 紹介画面から「ダイアルを試す」または「スライダーを使い続ける」を選べる。
- Zone 2は現在の実装が絶対音量指定を行わないため、従来の操作UIを維持する。

## ダイアル操作仕様

- 対応範囲: `-80.0...18.0 dB`
- 変更単位: `0.5 dB`
- 約5度の回転を1ステップとして扱う。
- 円周をまたぐドラッグでも回転方向が反転しないよう、角度差を正規化する。
- ドラッグ中は画面上の値だけを即時更新し、AVRへの絶対音量コマンドは指を離した時に1回送る。
  これにより、操作感を保ちながらネットワークコマンドの連打を避ける。
- iOS/iPadOSでは各ステップに選択フィードバックを返す。
- VoiceOverでは「音量ダイアル」と現在のdB値を読み上げ、増減アクションで操作できる。

## ビジュアル

白〜金属色の立体的な円形ノブ、外周の目盛り、現在位置を示すアクセントカラーのドットで構成する。
ミュート中はアクセントをオレンジに変え、中央のスピーカーアイコンもミュート表示にする。

## 永続化と初回紹介

| UserDefaultsキー | 値 | 用途 |
|---|---|---|
| `volumeControlStyle` | `slider` / `dial` | 選択中の音量UI。未設定時は`slider` |
| `hasShownVolumeDialIntroductionV1` | `Bool` | バージョン1のダイアル紹介を表示済みか |

初回紹介とApp Storeレビュー依頼が同時に現れないよう、未表示の紹介を優先する。レビュー依頼の条件は
消費せず、次回以降の接続成功時に再評価する。

## App Storeレビュー依頼の確認結果

レビュー依頼は追加済みであり、次の条件をすべて満たした接続成功時にSwiftUIの
`RequestReviewAction`を呼ぶ。

- 接続成功が3回以上
- 初回の接続成功から2日以上経過
- 現在のアプリバージョンではまだ依頼していない

設定画面にはユーザーが自分で選べる「レビューを書く」操作もある。満足度や評価点でユーザーを選別せず、
成功体験の後に中立的なシステムレビュー画面を提示する設計としている。

## 検証

- macOSターゲット: Debug build成功
- iOSターゲット: generic iOS device向けDebug build成功
- macOS実画面: スライダー初期表示、設定での切り替え、ダイアル表示、VoiceOverの増減アクションを確認
- 実機AVRへの音量送信とiPhone実機の触覚はリリース前にTestFlightで最終確認する

## 収益化との関係

ダイアルは既存の音量操作を改善する基本機能として無料のまま提供する。最初の収益化は操作機能を
取り上げる形にせず、任意の開発支援IAPを推奨する。繰り返し支援なら消耗型、恒久的なSupporter特典を
付けるなら非消耗型とし、商品構成・価格は別途合意してからStoreKit実装に着手する。
